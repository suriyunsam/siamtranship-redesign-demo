# Siam Tranship — homepage redesign demo

A static design demo of a proposed homepage for [siamtranship.com](https://www.siamtranship.com).
It is not the live booking site: every "Book" button goes to the real site.

- Live demo (English): https://suriyunsam.github.io/siamtranship-redesign-demo/
- Live demo (Thai): https://suriyunsam.github.io/siamtranship-redesign-demo/th/
- Two pages, `index.html` and `th/index.html`, no build step.
- The price calculator uses the current zone rate table; departure dates are shown as `[Date]` placeholders.
- Images and videos load from siamtranship.com and its existing storage.
- The page is marked `noindex` so it never competes with the real site in search.
